# Project-Home-Finder
This is a simple Angular 20 project.

# Functionality Along With Key Features
- Product Listing with search functionality.
- Product Detail Page. Click **Learn More** from the Product Card.
- Simple Contact Form with basic validation using Angular reactive forms.
- Dynamic Routing.
- SSR and SSG.
